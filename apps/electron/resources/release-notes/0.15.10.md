## Features

- **Agents can read other sessions** — A new `get_session_messages` tool lets the agent read another session's conversation in this workspace: your messages and its replies, with tool calls shown as one-line summaries. It reads 5 messages at a time and can page back and forward. For a branched session it can skip the part copied from the original. Coding sessions have it too. A message one session sends to another now tells the receiver it can read the sender's conversation this way.
- **@-mention a session** — Type `@` in the input to pick a session from this workspace. Running sessions are listed first, and search finds any session by title. The mention shows as a badge with the session's title, and the agent reads that session when it needs the context.
- **Quote a reply into another session** — The new **Copy quote** button under each reply copies a reference to that point in the conversation, starting at the question you asked. Paste it into any session's input; the agent reads the conversation from there.
- **Drag sessions into the input** — Drag a session from the session list into a chat input to mention it. Dragging a multi-selection mentions all of them.

## Improvements

- **Copy Session ID** — The session menu's **Copy Path** item is now **Copy Session ID**, the ID agents use to reach a session.
- **Sessions open when you release the click** — A plain click in the session list now opens the session when you release the mouse button instead of when you press it, so dragging a session no longer opens it. Cmd-click, Shift-click and right-click work as before.

## Bug Fixes

- **@-search accepts non-English text** — Typing a non-English query after `@` (for example Chinese or Japanese) closed the menu immediately, so sessions and files with such names could not be found. The menu now stays open and searches them.
