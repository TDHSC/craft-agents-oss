## Features

- **In-place edit and re-send for sent messages** — Click any sent user message bubble to expand it directly into the full composer (model picker, thinking level, attachments, `@` mentions, and send button). Submitting truncates that turn and anything after it, rewinds the active Claude or Pi conversation in place to the last kept reply without opening a separate branch, and sends the updated prompt. Pressing `Esc` or clicking outside restores the original bubble without disturbing an in-flight response.

## Improvements

- **Self-hosted GitHub Releases update channel** — Auto-updates and installer scripts now pull releases from [`TDHSC/craft-agents-oss`](https://github.com/TDHSC/craft-agents-oss/releases) so upstream releases do not overwrite custom builds.
