## Bug Fixes

- **Symlinked skills load** — A skill folder that is a symbolic link (for example `.agents/skills/interview -> ~/my-skills/interview`) was skipped, so linked project skills never appeared in the `@` menu and `[skill:…]` mentions of them did not resolve. Linked skill folders now load from all three places: `~/.agents/skills`, the workspace and the project.
- **Project skills stay in the `@` menu** — Adding, removing or editing a workspace skill dropped the project's skills from the `@` menu until you switched sessions. The menu now keeps them, and an edited skill's name and description show up right away instead of up to five minutes later.
